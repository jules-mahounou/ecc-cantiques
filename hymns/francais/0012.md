I
Chantez ce beau cantique
Pour acceuillir le fils de Dieu
Qui vient dans une grande Gloire
Afin de nous sauver
Chantez ce beau cantique
Pour acceuillir le fils de Dieu

II
Chantez ce beau cantique
La Sainte Eglise est venue
Purifier le Pécheur
Pour l'emmener vers Dieu
Chantez ce beau cantique
La Sainte Eglise est venue

III
Vous les enfants du Christ
Adorez-le dans l'union
Il suivra vos prières
Les transmettra au Père
Vous les enfants du Christ
Adorez-le dans l'union

(Amen)
