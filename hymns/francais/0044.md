I
Publiez tous le Nom de Jésus (bis)
Portez la lumière dans les ténèbres
Qu’à la fin Sa Parole s’accomplisse.

II
Que tous les peuples croient en Jésus Christ. (Bis)
Que les pécheurs viennent se repentir
Pour entrer dans la Cité Céleste.

III
Publiez tous le Nom du Seigneur (bis)
Pour le salut gratuit qu’il nous donne
Alléluia pour la Saint Eglise.

(AMEN)
