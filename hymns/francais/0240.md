I
Restez unis, Restez unis
Avec un grand amour
Il nous faut prier à tout moment
Soyer soumis à l’Eternel Dieu
Entraidez- vous les uns, les autres
Dans la sainte communion

II
Préparez- vous dans l’union
L’Eglise de Dieu est unique
Que ce ne soit pas dans l’orgueil
Ni dans les désordres, les divisions.
Soyer soumis les uns aux autres
Dans le respect des Saints

III
Eviter les propos fâcheux
Et les mauvaises pensées
L’Eglise est basée sur l’amour
C’est dans l’amour que sont les saints
Pour servir l’Eternel

(AMEN)
