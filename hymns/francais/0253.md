1.
C'est l'heure de repentance
Hâte-toi donc pour la vie éternelle.

REFRAIN:
La Sainte Eglise est venue,
Christ appelle le pécheur,
Les adeptes de satan,
Leur barque échouera dans l’enfer.

2.
Ce monde est vanité
Ainsi que tout ce qu'il renferme.
REFRAIN: La Sainte Eglise est venue ...

3.
« Saint » que nous prononçons
N’est pas destiné pour ce monde
REFRAIN: La Sainte Eglise est venue ...

4.
L’heure du père est venue
Faites la grande ouvres d’amour
REFRAIN: La Sainte Eglise est venue ...

(AMEN)
