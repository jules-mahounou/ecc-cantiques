# Code de conduite

Le projet ECC-Cantique accueille tout le monde avec respect. En participant, tu t'engages à :

- faire preuve de **bienveillance et de respect** envers les autres ;
- accepter la critique constructive ;
- ne pas tenir de propos ou comportements harcelants, discriminatoires ou offensants.

Les mainteneurs peuvent retirer, modifier ou refuser toute contribution
(commentaires, commits, issues, PR) non conforme à ce code, et bannir
temporairement ou définitivement tout contributeur au comportement inapproprié.

Pour signaler un problème, ouvre une issue ou contacte un mainteneur en privé.

Ce code s'inspire du [Contributor Covenant](https://www.contributor-covenant.org).
